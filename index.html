Open source for KDE Plasma 6

Windows 11 search, on your Linux desktop.

Lumen is a calm flyout with your recent apps and a search box at the bottom. Built for KDE Plasma 6 on Wayland with Quickshell.

The panel at a glance. Here is what you are looking at.

  • Recent listApps and actions you used lately, each with a time stamp.

  • Search at the bottomStart typing and the list narrows down.
  • Power buttonSits next to the search box for quick access.

Where the idea came from

Windows 11 has a search flyout that feels right: a short list of what you used lately and a search field right where your hand already is.

Plasma has great launchers, but none copy that layout. This project brings it over and rebuilds it for Linux.

The goal is a panel that feels calm and quick, with nothing on it you didn't ask for.

Install in a minute

Pick a method. Every command has a copy button.

1. Install Quickshell

On Arch. For other distros, see Compatibility above.

sudo pacman -S quickshell

2. Clone and install

The script sets up the config and the user service.

git clone https://github.com/Opickle/Lumen.git
cd Lumen
./install.sh

3. Bind a key

Open System Settings, go to Shortcuts, then Add Application. Pick Quicksearch Toggle and assign a key, like Alt+Space.

4. Test without the shortcut

Toggles the launcher from the terminal.

qs -c quicksearch ipc call launcher toggle

Install everything

Installs Quickshell, clones the repo, and runs the installer. Then bind your key in System Settings.

sudo pacman -S quickshell && git clone https://github.com/Opickle/Lumen.git && cd Lumen && ./install.sh

Customize

Edit the SETTINGS block at the top of shell.qml (colors, size, position, number of results), then restart.

nano ~/.config/quickshell/quicksearch/shell.qml
systemctl --user restart quicksearch

Troubleshoot

Check the service and read the last log lines.

systemctl --user status quicksearch
journalctl --user -u quicksearch -n 30

Uninstall

Run from the cloned folder. The first keeps your launch history, the second deletes it too.

./uninstall.sh
./uninstall.sh --purge

Requires KDE Plasma 6 on Wayland.
